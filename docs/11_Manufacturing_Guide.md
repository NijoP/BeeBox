# 11 — Manufacturing Guide

## Release package
For each main PCB and FPC release: Gerbers, NC drill, fab drawing, stackup/impedance request, IPC land-pattern notes, assembly drawing, centroid/pick-and-place, AVL BOM, paste layers, panel drawing, fiducials, programming/test procedure and revision-controlled change list. For FPC add coverlay, stiffener, bend/keepout drawing and connector mating specification.

## DFM/DFA
Obtain supplier review for annular rings, fine pitch, soldermask slivers, edge plating, flex copper/coverlay, stiffener, panel yield, adhesive and bend cycles. Use X-ray/AOI for hidden joints where applicable; define connector inspection, pogo contact force/alignment and magnet polarity. Separate PCB/FPC fabrication, component sourcing, assembly, engineering/NRE, tooling/setup and test fixture quotes.

No production package exists yet. Prototype assembly should include first-article inspection and a documented build traveler.
